# 実録音のローカル管理

2026-10-30 JST。根拠は Issue #1・#7 の研究グループ外共有制限と、今回ユーザーが確認したローカル学習・評価の利用許諾。ユーザーの追加指定に従い、実験対象は **`14412_0.35s.wav` のみ**。1秒版の内容読込み、別音節への切出し、追加録音の取得は行わない。

## 今回行ったこと

- `sample_song/` と `private_runs/` を `Deeplearning/.gitignore` の対象とした。
- もともと追跡されていた原音2ファイルは `git rm --cached` でインデックスから除外した。削除がステージされているが、ディスク上の原本は両方とも残してある。
- 原音、目標の複製、生成音、モデル重み、制御軌道、実録音に基づく詳細な誤差表・図は `private_runs/` のみで扱う。GitHub へのアップロード、Issue コメントへの添付はしていない。
- 実録音実験は出力先を `private_runs/` 配下に限定し、`umask=077` とする。音声はローカルパスから読み込み、ファイルのパスや波形値を公開ログへ保存しない。
- 0.35秒の区間選択、元サンプル数、末尾の調整量、リサンプリング率、共通のゲイン校正は非公開の `private_runs/phase2/config.json` に記録する。原音は上書きしない。

## 残っている対応

**インデックスからの除外や `.gitignore` は、既存履歴・公開済みファイルを消さない。** ローカル履歴では `80cc47e` に原音が含まれることを確認した。今回、コミット、push、履歴書換え、リポジトリ公開範囲変更は行っていない。

管理者側で許諾元と共有状態を確認し、公開範囲の制限、現在のブランチからの削除反映、必要なら履歴全体の除去を検討する必要がある。履歴の除去は他の共同研究者の clone・fork・キャッシュまで自動回収しない。履歴書換えと force-push は共同作業に影響するため今回実施していない。バックアップを含む保存先の共有範囲も、研究グループ内に限定する。

`git add -f` は除外設定を無視するため使わない。新しい原音を配置する場合も公開ツリーへの追加を避け、ローカル管理下に置く。非公開成果物の共有にも原音と同じ保守的な管理方針を適用する。
